# productivity-cli

Personal productivity CLI scripts, syncable across machines.

The custom Todoist CLI (`td`) has been retired. Use the Homebrew package
instead:

```bash
brew install todoist-cli
todoist --version
```

This repository is currently an empty shell for future local productivity
tools. Add new executables under `bin/` and run `bash install.sh` to copy them
to `~/.local/bin`.
